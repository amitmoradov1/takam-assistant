# תסריט מוצע לסרטון ההדגמה (עד 3 דקות)

> הקלטת מסך + קריינות. לתרגל פעם אחת לפני ההקלטה; לכוון ל-2:30.

## 0:00–0:25 — הבעיה (על רקע אתר התכ"ם הפתוח)
"זה אתר הוראות התכ"ם. נניח שאני רכז רכש וצריך לדעת עד איזה סכום מותר לי
לבצע רכש בהליך מקוצר. אני צריך לדעת מראש שזה בהוראה 7.7.1, לפתוח מסמך
Word ארוך, ולמצוא לבד את הסעיף. חיפוש חופשי בעברית מפספס בגלל הטיות —
'התקשרות' מול 'ההתקשרויות'."

## 0:25–0:50 — הפתרון במשפט + מסך הפתיחה
"בניתי עוזר שאלות-תשובות מבוסס RAG: שואלים בשפה חופשית, המערכת שולפת את
הסעיפים הרלוונטיים מתוך 8 הוראות אמיתיות שנאספו מפרק 'התקשרויות ורכישות'
באתר, ו-Claude מנסח תשובה אך ורק מתוכם — עם ציטוט מדויק ברמת הסעיף."

## 0:50–1:50 — דמו חי (שלוש שאלות)
1. "מהי תקרת הסכום להתקשרות בהליך רכש מקוצר?" → להראות את התשובה, את
   הציטוטים [מקור 1] ("הוראה 7.7.1, סעיף 2.1"), ואת הקישור לנוסח המלא.
2. "מה נדרש כדי לאשר התקשרות עם ספק יחיד?" → להדגיש שהציטוט מגיע מנספח:
   "הוראה 7.6.1, נספח ג, סעיף 6.1" — המערכת משחזרת את מבנה הסעיפים
   והנספחים מתוך קובצי ה-Word של האתר, כולל המספור האוטומטי.
3. שאלה שאין עליה תשובה במאגר (למשל "מה שעות הפתיחה של משרד האוצר?") →
   להדגיש שהמערכת אומרת "לא נמצא במקורות" במקום להמציא. בתחום רגולטורי
   זו התכונה החשובה ביותר.
4. להצביע על "הוראות קשורות" מתחת לתשובה: "המערכת מחלצת אוטומטית את
   ההפניות הצולבות — 'בהתאם להוראת תכ"ם, מס' X' — ובונה מהן גרף דו-כיווני.
   כששואלים על פטור ממכרז, היא מציעה גם את הוראות ההליך המקוצר והערבויות."

## 1:50–2:20 — מבט מהיר על הקוד והארכיטקטורה
להראות את תרשים הזרימה ב-README ולומר:
"צנרת אופליין: איסוף דרך ה-API הפנימי של האתר ← חילוץ DOCX עם שחזור מספור
הסעיפים של Word ← פירוק היררכי ← אינדקס BM25 מותאם עברית. אונליין: אחזור ←
Claude עם prompt שמחייב עיגון במקורות. הליבה דטרמיניסטית ומכוסה ב-56
בדיקות, איכות האחזור נמדדת מול סט זהב (recall@5 ‏100%) עם שער ב-CI,
וה-LLM מבודד בקובץ אחד — בסביבה סגורה מחליפים אותו במודל מקומי."
אפשר להריץ `python -m pytest tests/ -v` על המסך.

## 2:20–2:50 — סגירה
"בלי מפתח API המערכת עדיין עובדת במצב אחזור בלבד — graceful degradation,
וכל כשל ב-API מדרדר לשם אוטומטית. ב-README פירטתי מה נדרש ל-Production:
צנרת עדכונים מההוראות (זיהוי הגרסאות כבר קיים), אחזור היברידי, evals מול
רפרנטים, והתאמה לרשת ממשלתית סגורה עם מודל מקומי."

## טיפים טכניים
- להקליט בחלון דפדפן נקי ברוחב מלא; להגדיל גופן טרמינל.
- לוודא לפני ההקלטה: `python scripts/build_index.py` רץ על data/raw
  (8 הוראות, ~960 קטעים) ו-ANTHROPIC_API_KEY מוגדר.
- כלי הקלטה: OBS / הקלטת המסך של macOS (Cmd+Shift+5) / Loom.
